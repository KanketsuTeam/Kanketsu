# 🚀 快速开始

本指南将带你使用 Kanketsu 构建第一个命令行应用。

学完本指南后，你将掌握：

* 🧩 创建一个 CLI 应用。
* 🌳 注册命令。
* ⚙️ 定义选项。
* 🧾 获取用户输入。

---

## 📋 前置要求

开始之前，请确保已安装：

* ☕ Java 17 或更高版本
* 📦 Maven

添加核心依赖：

```xml
<dependency>
    <groupId>io.github.kanketsuteam</groupId>
    <artifactId>kanketsu-core</artifactId>
    <version>2.1.0</version>
</dependency>
```

---

## 📦 导入

在 Java 源文件中，通常需要导入：

```java
import core.io.github.kanketsuteam.kanketsu.CLI;
import converter.core.io.github.kanketsuteam.kanketsu.Converters;
```

---

## 👋 你的第一个命令

每个 Kanketsu 应用都从 `CLI` 构建器开始。

```java
CLI.builder()
    .command("hello", cmd -> cmd
        .action(ctx -> System.out.println("Hello, Kanketsu!")))
    .build()
    .execute("hello");
```

运行应用输出：

```text
Hello, Kanketsu!
```

恭喜！你已经创建了第一个 Kanketsu 应用。

---

## 🌳 构建命令树

真实的 CLI 应用通常包含多个命令。

命令可以嵌套，形成命令树。

```java
CLI cli = CLI.builder()
    .command("git", git -> git
        .command("commit", commit -> commit
            .action(ctx -> System.out.println("Commit executed"))))
    .build();

cli.execute("git", "commit");
```

该结构表示：

```text
git
└── commit
```

每个命令可以包含子命令、选项和 action。

---

## ⚙️ 添加选项

选项用于改变命令的行为。

```java
CLI cli = CLI.builder()
    .command("echo", command -> command
        .option("message", option -> option
            .shortOpt("m")
            .hasArg(true)
            .converter(Converters.STRING))
        .action(ctx -> {
            String message = ctx.getOptionValue("message", String.class);
            System.out.println(message);
        }))
    .build();
```

执行：

```text
echo --message "Hello"
```

或

```text
echo -m "Hello"
```

两种方式结果相同。

---

## 📍 位置参数

未被解析为选项的参数会变为位置参数。

```text
copy source.txt destination.txt
```

可以通过命令上下文获取：

```java
List<String> args = ctx.getPositionalArgs();

String source = args.get(0);
String destination = args.get(1);
```

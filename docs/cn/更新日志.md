# 更新日志

## [2.1.0] - 2026-08-08

### ✨ 新增

- 为 Kanketsu-Core 的 `Option` 类补全了完整的 JavaDoc 文档。
- 为 Kanketsu-REPL 模块添加了 JavaDoc 文档。
- REPL 模块增强：
    - 新增 `TerminalLogger`，让终端编码不再是个麻烦事——Windows 用户现在可以自由使用 UTF-8 编码了。
    - 新增 `BuildTerminalFailedException` 运行时异常，用于处理终端创建失败的情况。
    - 新增 `Terminals` 工具类，用于快速构建 `Terminal` 实例。

### 🐛 修复

- 修复了 Kanketsu-Core 中 `CLI` 类的 `execute` 方法传入 `null` 时抛出异常的问题。

### 🤔 新功能怎么用？

在 CLI builder链中添加以下代码：

```java
.logger(terminalLogger)
```

修改后的代码示例：

```java
Terminal terminal = Terminals.createDefault();

TerminalLogger terminalLogger = new TerminalLogger(terminal);
CLI cli = CLI.builder().logger(terminalLogger)
            // ... 其他构建器选项
        .build();
REPL repl = new REPL(cli, terminal);
```

**⚠️ 注意：`createDefault` 方法会抛出 `BuildTerminalFailedException` 运行时异常，如需特殊处理请记得捕获。**

## [2.0.0] - 2026-08-05

### ⚠️ 破坏性变更

- **移除了 `Category` 枚举** —— 请改用 `Converters`：
  ```diff
  - .category(Category.INT)
  + .converter(Converters.INT)
  ```
- **`CommandContext.getOption()` 现在返回预转换的 `Object`** —— 请使用 `getOptionValue(String, Class<T>)` 进行类型安全的取值：
  ```diff
  - String msg = (String) ctx.getOption("message");
  + String msg = ctx.getOptionValue("message", String.class);
  ```
- **`CommandContext` 构造方法现在需要传入 `List<TypeConverter>`** —— 所有命令在构造上下文时必须提供已注册的类型转换器。

### ✨ 新增

- **混合选项支持** —— 选项现在可以出现在子命令之前，例如：`git --verbose commit`
- **严格子命令匹配** —— 未知子命令现在会抛出 `UnknownSubcommandException`
- **无 action 命令自动显示帮助** —— 没有绑定 action 的命令现在会自动展示帮助信息
- **系统属性 `kanketsu.autoHelp`** —— 用于控制自动帮助拦截的行为
- **类型安全的 `getOptionValue()`** —— 泛型方法，提供编译期类型检查
- **`Converters` 工具类** —— 预置了常用转换器：`STRING`、`BOOLEAN`、`INT`、`LONG`，以及自定义转换器 `of()`
- **`TypeConverter` SPI** —— Core 模块提供的类型转换扩展点
- **`getOptionValueAs(String, Class<T>)`** —— 使用已注册的 `TypeConverter` 将选项值转换为任意类型
- **`kanketsu-json` 模块** —— JSON 支持，能自动识别 JSON 字符串还是文件路径，精确定位错误，完全兼容 GraalVM Native Image
- **`JsonTypeConverter`** —— 零反射的 `JsonObject` 和 `JsonArray` 类型转换器
- **细化异常体系** —— 新增 7 种专用异常，覆盖不同的错误场景
- **`shortToLongMap` 缓存** —— 优化选项解析性能
- **`JsonExample`** —— 新增完整的 JSON 模块使用示例

### 🐛 修复

- 选项值转换异常现在会抛出 `OptionValueInvalidException`，并正确返回退出码 2
- `HelpGenerator` 现在能正确处理 null 命令
- `CommandBuilder` 在检测到重复子命令时会抛出 `CommandBuildException`
- `OptionValueInvalidException` 现在支持传入 `Throwable` 作为原因参数

# 💡 示例

本指南展示了使用 Kanketsu 构建的常见 CLI 模式。

它的目标不是穷举每一个 API，而是聚焦于解决你在构建命令行应用时可能遇到的实战问题。

---

# 👋 Hello World

最小可行的 Kanketsu 应用。

```java
CLI.builder()
    .command("hello", command -> command
        .action(ctx -> System.out.println("Hello, Kanketsu!")))
    .build()
    .execute("hello");
```

输出：

```text
Hello, Kanketsu!
```

---

# 🌳 嵌套命令

命令可以自然地嵌套，形成一棵命令树。

```java
CLI cli = CLI.builder()
        .command("git", git -> git
                .command("commit", commit -> commit
                        .action(ctx -> System.out.println("Commit created"))))
        .build();

cli.execute("git", "commit");
```

该结构表示：

```text
git
└── commit
```

嵌套命令是 Kanketsu 的核心构建块之一。

# ⚙️ 命令选项

选项用于定制命令的行为。

```java
CLI cli = CLI.builder()
        .command("echo", command -> command
                .option("message", option -> option
                        .shortOpt("m")
                        .converter(Converters.STRING)
                        .hasArg(true)
                        .description("要打印的消息"))
                .action(ctx -> {
                    String message = ctx.getOptionValue("message", String.class);
                    System.out.println(message);
                }))
        .build();
```

使用长选项或短选项执行：

```text
echo --message "Hello"
```

或

```text
echo -m "Hello"
```

---

# 🚩 布尔标志

布尔选项用作功能开关。

```java
.option("verbose", option -> option
    .shortOpt("v")
    .converter(Converters.BOOLEAN)
    .description("启用详细输出"))
```

示例：

```text
tool --verbose
```

或

```text
tool -v
```

在命令中取值：

```java
boolean verbose = ctx.getOptionValue("verbose", Boolean.class);
```

---

# ✅ 必填选项

将重要选项标记为必填。

```java
.option("title", option -> option
    .shortOpt("t")
    .converter(Converters.STRING)
    .hasArg(true)
    .required(true)
    .description("Issue 标题"))
```

在未提供必填选项的情况下运行命令，会在命令执行前报错。

---

# 🎁 默认值

当用户未指定时，选项可以提供默认值。

```java
.option("branch", option -> option
    .converter(Converters.STRING)
    .hasArg(true)
    .defaultValue("main")
    .description("目标分支"))
```

然后：

```java
String branch = ctx.getOptionValue("branch", String.class);
```

如果用户未提供值，返回 `"main"`。

---

# 📍 位置参数

未被解析为选项的参数会变为位置参数。

例如：

```text
copy source.txt destination.txt
```

在命令中：

```java
List<String> args = ctx.getPositionalArgs();

String source = args.get(0);
String destination = args.get(1);
```

位置参数保持其原始顺序。

---

# 🆘 内置帮助

每个命令都会自动生成帮助输出。

例如：

```text
tool --help
```

```text
tool build --help
```

```text
tool issue create --help
```

生成的帮助信息包括：

* 命令用法
* 命令描述
* 可用选项
* 必填选项
* 默认值
* 可用子命令

无需编写任何额外代码。

如果你想要使用不同格式的帮助生成，可以实现`HelpGenerator`接口，再重写generateDetailedHelp方法。在你的Builder链中传入你的HelpGenerator类即可。

如：
```Java
CLI .builder()
        .helpGenerator(YourHelpGenerator)
    //你的命令，选项等
    .build();
```
